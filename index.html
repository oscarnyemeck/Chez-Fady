Sauvegarde & transfert vers un autre ordinateur

Cette application enregistre normalement vos données dans ce navigateur (localStorage). Ce stockage reste sur cet ordinateur et peut être effacé (navigation privée, nettoyage du navigateur, changement de machine...). Pour éviter toute perte et pouvoir transférer vos données facilement, reliez un fichier de sauvegarde ci-dessous.

Aucun fichier de sauvegarde relié

⚠ Votre navigateur ne permet pas de relier un fichier automatiquement (fonctionnalité disponible sur Chrome ou Edge). Utilisez l'export / import manuel ci-dessous, et pensez à recopier le fichier exporté avec cette page HTML lorsque vous changez d'ordinateur.

Export / import manuel

Pour transférer l'application vers un autre ordinateur : copiez ce fichier HTML et votre dernier fichier de sauvegarde .json ensemble (clé USB, email, Google Drive...), puis ouvrez le HTML sur la nouvelle machine et importez la sauvegarde.

🔄 Synchronisation automatique multi-appareils

🔄 Connexion à la synchronisation…

Quand ce téléphone/ordinateur a Internet, les ventes et le stock se synchronisent automatiquement avec tous les autres appareils connectés au même compte. Sans réseau, l'app continue de fonctionner normalement et enverra les changements dès la reconnexion.

Utile une seule fois pour choisir quel appareil devient la référence (par ex. après avoir testé l'app sur une machine de conception séparée de celle qui contient les vraies ventes).

📤 Transfert manuel (secours, sans Internet)

Envoie directement le fichier de sauvegarde vers WhatsApp, Bluetooth, Google Drive, etc. depuis le téléphone qui contient les données les plus récentes, puis ouvre l'app sur l'autre appareil et importe ce fichier via « Importer une sauvegarde » ci-dessus.

🔔 Alertes intelligentes

Chaque jour à l'ouverture, l'application signale automatiquement les ruptures de stock, les produits proches de la péremption et les suggestions de réapprovisionnement. Active les notifications pour être averti même si l'onglet est en arrière-plan (utile une fois l'app installée sur ton téléphone).
